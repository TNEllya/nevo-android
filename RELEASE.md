# NEVO Android v1.0.0 Release Notes

## Features
- Server connection management
- Channel browsing and voice/text channels
- Real-time text chat with emoji support
- Voice call support
- Screen sharing
- Multi-language (English/简体中文/繁體中文)
- Online update support via GitHub Releases

## Requirements
- Android 8.0+ (API 26)

Built with Kotlin + Jetpack Compose + Hilt + JNI
